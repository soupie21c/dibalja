# 디발자 (Designer + Developer)

회사에서 디자인을 하면서 개발을 공부하는 기록입니다.

## 목표

- 디자인한 화면을 직접 코드로 만들 수 있기
- 개발자와 같은 언어로 이야기하기
- Git과 GitHub로 작업을 관리하는 습관 들이기

## 폴더 구조

| 폴더 | 내용 |
|---|---|
| `notes/` | 공부하면서 정리한 노트 |
| `practice/` | 직접 만들어 본 실습 코드 |
| `crit-board/` | full-stack-designer 1부 실습 — Figma 디자인 시스템을 Next.js + shadcn/ui로 옮긴 디자인 크리틱 보드 |
